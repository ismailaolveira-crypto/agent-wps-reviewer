# 修改目的与效率门

每条正式意见至少对应一个修改目的：

- `chapter-focus`：让章节和小节完成自己的核心任务。
- `evidence-accuracy`：保证事实、数据、分母、来源和结论边界可靠。
- `structure-logic`：解决标题、段落、编号、图表和论证关系问题。
- `compression`：压缩重复、空泛铺垫和无效例子，同时保留证据与判断。
- `anti-ai-tone`：去除宣传腔，改成明确主体、机制、证据和边界。
- `historical-style`：保持与 2022-2024 年同系列白皮书的内容风格一致。
- `human-boundary`：把强判断、重大删改和传播表达留给编委确认。

每条意见还必须降低审稿成本：位置能直接定位，问题能快速判断，作者知道下一步动作。若审稿人理解和核对该批注花费的时间大于修改收益，该意见不进入候选列表，不得提交。

下列内容直接淘汰：

- “建议优化”“逻辑不清”等没有对象和动作的意见；
- 只因一句话还能润色就生成的意见；
- 已被前后文解释或解决的问题；
- 为显得全面而要求补背景、补案例、补定义；
- 没有证据的事实核验和历史风格判断；
- 过短、重复或无法唯一定位的锚点。
