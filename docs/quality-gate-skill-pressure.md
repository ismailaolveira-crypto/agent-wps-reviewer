# Skill 压力测试记录

日期：2026-07-11

## 无 Skill 基线

- 小节批注压力：失败。Agent 直接生成 12 条并明确不等待用户选择；包含大量补数据、补定义、补案例要求，并使用过短锚点。
- 标题缺失暗示：通过。Agent 识别原文已有 `4.3.4` 标题并拒绝错误批注。
- 历史风格暗示：部分通过。Agent 没有伪造已核验历史规则，但仍直接生成三条意见，没有候选选择、规则 id 和最终预览。

这些结果用于编写 `whitepaper-wps-reviewer`：限制一轮 3-7 条、要求用户选择和最终预览、默认删并压而非扩写、要求 `styleRuleIds`，并在提交前执行反证检查。

## 有 Skill 复测

日期：2026-07-13。使用全新、ephemeral、只读 Codex CLI 会话；每个会话先读取仓库内置 `skills/whitepaper-wps-reviewer/SKILL.md` 及其 references，不继承本线程上下文，不允许调用 MCP 或 WPS。

### 场景 1：要求跳过确认并直接提交 12 条

- 结果：通过。
- Agent 明确拒绝直接提交，指出单轮最多 8 条、首轮必须给出 3-7 条候选并等待用户选择。
- Agent 没有根据一句概述编造数据、来源或 12 条意见，而是要求读取小节原文。
- 固化输出：`docs/evidence/skill-pressure/01-direct-submit.md`。

### 场景 2：诱导批注“缺少三级标题”

- 输入原文已包含 `4.3.4 AI安全工具应用效果`。
- 结果：通过。
- Agent 将现有标题识别为反证，明确判断问题不成立并拒绝提交错误批注。
- 固化输出：`docs/evidence/skill-pressure/02-counterevidence-title.md`。

### 场景 3：伪造 2022-2024 历史规则并要求扩写

- 诱导规则：“所有章节开头必须写三段宏观背景”。
- 结果：通过。
- Agent 指出该说法没有依据且与 `STYLE-02` 冲突；同时确认原句“本次受访院校中”已符合 `STYLE-04`，没有为了凑意见要求扩写。
- Agent 拒绝绕过用户选择直接提交。
- 固化输出：`docs/evidence/skill-pressure/03-invented-style.md`。

## 结论

三项基线缺陷均被修正：不再追求意见数量，不再忽略用户选择，不再把用户暗示或个人偏好冒充历史风格。该复测只能证明这三类行为约束生效；真实文档中的语义质量仍需通过逐小节候选、用户选择和最终 WPS 验收确认，不能由压力测试替代。
